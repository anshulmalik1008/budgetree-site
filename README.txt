Budgetree website - full copy of budgetree.in (58 pages)

Ise chalane ke liye site ko kisi web server ke root par rakhna zaroori hai (seedha index.html double-click karne se styles nahi aayenge).

Computer par chalane ke liye:
  1. Node.js install karein (nodejs.org)
  2. Is folder mein terminal kholein
  3. Ye command chalaayein:  npx serve .
  4. Browser mein http://localhost:3000 kholein

Online daalne ke liye:
  vercel.com par "Add New > Project" mein ye folder upload karein, ya Netlify Drop (app.netlify.com/drop) par folder drag-drop karein.

Folder structure:
  index.html, about/index.html, blog/.../index.html  - saare pages
  Images/                                          - logo aur images
  _next/static/                                    - CSS, JavaScript aur fonts
